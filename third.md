1. Project Overview
Краткое описание приложения, архитектуры и технологического стека.

2. Mandatory Context
Укажи документы, которые необходимо изучать перед выполнением определённых типов задач.

3. Architecture Rules
Опиши только подтверждённые архитектурные ограничения.

4. React & TypeScript Rules
Зафиксируй обязательные соглашения разработки.

5. Code Reuse
Обяжи проверять наличие существующих компонентов, хуков, утилит и типов перед созданием новых.

6. Change Scope
Требуй минимальных изменений, связанных с задачей. Запрети несогласованный рефакторинг.

7. Dependencies
Запрети добавление или обновление зависимостей без разрешения.

8. Task Execution
Опиши стандартную последовательность:
- понять задачу;
- найти релевантный код;
- изучить существующие паттерны;
- предложить план;
- реализовать согласованное решение;
- выполнить доступные проверки;
- представить отчёт.

9. Validation
Используй реальные команды проверки из package.json.

10. Safety
Запрети раскрытие секретов, обход ограничений проекта и утверждения о выполненных проверках без фактического запуска.
